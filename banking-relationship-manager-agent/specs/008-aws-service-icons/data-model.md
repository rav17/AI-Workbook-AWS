# Data Model: AWS Service Icons in Architecture Diagram

This documentation-only feature adds no application data entities. The diagram uses the following visual mapping:

| Diagram element | Representation | Notes |
|---|---|---|
| AWS-managed service | Existing labeled card with a native AWS4 icon | Prefer a verified service-specific stencil; use the verified machine-learning category icon for AgentCore/Bedrock where no dedicated icon is confirmed |
| Custom application component | Existing generic labeled card | No AWS service icon |
| Human role or external provider | Existing actor or external-system card | No AWS service icon |
| Architecture flow | Existing edge connected to its original card cell | Preserve source and target IDs |
